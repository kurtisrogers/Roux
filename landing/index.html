Everything you need to compete with legacy SaaS

📅 Operations Dashboard

Sessions, bookings, check-in/out, multi-site management, and role-based access for your whole team.

🌐 CMS Website Builder

Drag-and-drop page builder with visual editors. Parents book and pay online from your branded site.

💳 Stripe & Xero

Session payments via Stripe Checkout. Automatic invoice sync to Xero for painless accounting.

📋 Ofsted Compliance

Incident logging, UK EYFS staff:child ratio checks, monthly reports, and CSV exports.

📱 Mobile API

JWT-authenticated REST API for iOS and Android apps. Children, sessions, bookings — all covered.

✉️ Parent Notifications

Automatic emails for bookings, payments, check-in, and check-out. Staff session reminders too.

Run your own wraparound business

Become a Roux franchise partner — each partner gets an isolated database, branded website, and their own Stripe & Xero integrations. Apply online and track your application from Pending → Under Review → Partner.

Built for UK regulation

Statutory staff:child ratios, Ofsted-notifiable incident tracking, emergency contact management, allergy and medical notes — Roux is designed for the realities of UK wraparound care.

Modern, extensible stack

Django · Pico CSS · HTMX · Alpine.js · Playwright · SST on AWS

Get started in minutes

git clone https://github.com/kurtisrogers/Roux.git
cd Roux
pip install -r requirements.txt -r requirements-dev.txt
python manage.py migrate && python manage.py seed_demo
python manage.py runserver

Demo logins: admin / admin123 · parent1 / parent123
