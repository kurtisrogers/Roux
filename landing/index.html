Get started in minutes

Clone the repo, seed demo data, and explore the dashboard and parent booking flow locally.

git clone https://github.com/kurtisrogers/Roux.git cd Roux pip install -r requirements.txt -r requirements-dev.txt python manage.py migrate && python manage.py seed_demo python manage.py runserver

Demo logins: admin / admin123 · superadmin / super123 · parent1 / parent123
