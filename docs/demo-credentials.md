# Demo credentials

After running `python manage.py seed_demo`:

| Role | Username | Password | Access |
|------|----------|----------|--------|
| Super Admin | `superadmin` | `super123` | Platform-wide franchise provisioning |
| Org Admin | `admin` | `admin123` | Full dashboard, CMS, billing, users |
| Staff | `staff1` | `staff123` | Sessions, register, check-in/out |
| Parent | `parent1` | `parent123` | Public site, child profiles, bookings |

Demo organisation: **Oakwood Wraparound Club** with breakfast and after-school sessions, childcare vouchers, and recurring bookings.
